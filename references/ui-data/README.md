# UI reference data

Searchable tables copied from [ui-ux-pro-max-skill](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill) by Next Level Builder (MIT; see NOTICES.md). Any AI can read these CSV files directly; no tool needed. Used mainly by `04-ui-design/visual-direction`.

| File | What it holds |
|---|---|
| products.csv | Product types and the styles and patterns that suit them |
| styles.csv | UI styles with colours, effects, best and worst uses, accessibility notes |
| colors.csv | Palettes by product type |
| typography.csv | Font pairings with mood and use |
| ui-reasoning.csv | Rules linking product, style, colour and type choices |
| ux-guidelines.csv | Do and do-not UX rules with severity |
| landing.csv | Landing page patterns |
| charts.csv | Chart types by data question |
| motion.csv | Motion patterns |
| app-interface.csv | App interface patterns |

Treat the data as suggestions to choose from, then record the choice in DESIGN.md.
